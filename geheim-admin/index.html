Hoe werkt het?

  1. Klant logt in → klikt op "Bestel Privacy Kaart"
  2. Jij ontvangt een e-mail melding via Netlify
  3. Jij ontvangt betaling (bank/contant naar jouw keuze)
  4. Jij genereert hier een code voor het e-mailadres van de klant
  5. Stuur de code via WhatsApp naar de klant
  6. Klant voert code in → downloadt eenmalig haar Privacy Kaart PDF
  7. De code wordt automatisch geblokkeerd na gebruik
